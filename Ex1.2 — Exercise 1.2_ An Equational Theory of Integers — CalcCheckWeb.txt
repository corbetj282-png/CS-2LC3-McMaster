LADM lists both identity laws, but after introducing symmetry, and long after starting to use symmetry
properties implicitly.
We could follow that, but since we already activated the symmetry above, explicitly listing both identity
laws “0 + a = a” and “a + 0 = a” with the same name would only mean that everywhere one of these
applies, both are found, and both would be tried successfully as non-last steps, which would only slow
down proof checking.
