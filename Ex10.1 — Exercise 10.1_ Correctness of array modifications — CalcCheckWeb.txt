The type of length-(k + 1) arrays with element type A can then be modeled as the following set:
(0 ‥ k) ⇴ ⌞ A ⌟
Array lookup a[i] then is just partial function application, as seen in A2.1:
a @ i
Array update a[i] := E can be formalised via relation override _⊕_ (seen in Ex8.2 and in the Reference Notebookk “Operators Combining
Sets and Relations”):
a := a ⊕ { ⟨ i , E ⟩ }
There is no easier way to reason about array manipulations in Hoare logic!
