This additional variable is intended as a so-called “ghost variable”:
Its values do not influence the control flow
Its values do not influence the values of “proper” program variables
Its values therefore do not influence the result of the program
It is needed only to make the invariant easier to state, and easier to prove.


The overall structure required for proving this correct is the same as in Ex10.3, and we aim for the same postcondition:
b ≡ x ∈ xs₀
In Ex10.3, you were provided with the following sufficient invariant, which has us as a logical variable that does not occur in the program:
∃ us • (us ⌢ xs = xs₀) ∧ (b ≡ x ∈ us)
In this notebook, the corresponding correctness proof can use a simpler invariant, which refers to the additional (ghost) program variable us:
(us ⌢ xs = xs₀) ∧ (b ≡ x ∈ us)
