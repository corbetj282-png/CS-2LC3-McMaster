The set-up here for commands and dynamic-logic assertions about command correctness is the same as
in H3:
We use the type Cmd for commands of a simple imperative language.
Assignment commands are constructed using _:=_ : t → t → Cmd, and currently have to have a single
variable as first argument.
Note that the assignment symbol “:=” used here consists of the two characters : and =, and is different
from the “≔” used for substitutions.
Sequential composition of commands is expressed using the binary sequencing operator _⍮_ : Cmd →
Cmd → Cmd; type “\;_” to obtain that underlined semicolon symbol. Sequencing _⍮_ is associative, and
that associativity is activated, so that parentheses in commands like “C₁ ⍮ C₂ ⍮ C₃” are not necessary.
Instead of writing Hoare triples “❴ P ❵ C ❴ Q ❵” as you see them in LADM, we use the mixfix operator
_⇒⁅_⁆_ to write them as “P ⇒⁅ C ⁆ Q” in the style of dynamic logic.
Since the simple square brackets are reserved for substitution, the brackets in this operator have “quills”,
and are obtained by typing “\[-” for “⁅” and “\]-” for “⁆”.
The assignment axiom therefore takes the following shape:
“Assignment”:

[2]

Q[x ≔ E] ⇒⁅ x := E ⁆ Q
