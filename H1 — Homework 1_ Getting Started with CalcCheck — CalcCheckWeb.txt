Welcome to 2LC3!
In this class we aim to teach you to reason effectively by starting out with making all reasoning steps explicitly
clear.
Some calculations were shown in the first lecture; the general shape of a calculation is a sequence of expressions,
where two consecutive expressions are separated by a calculation operator (such as = or ≡ or ⇒) and a hint
enclosed in angle brackets “⟨” and “⟩”, which in this role are also referred to as hint brackets:
Calculation:
⟪expression⟫
⟪calcOp⟫⟨ ⟪hint⟫ ⟩
⟪expression⟫
⟪calcOp⟫⟨ ⟪hint⟫ ⟩
...
⟪calcOp⟫⟨ ⟪hint⟫ ⟩
⟪expression⟫
In this kind of presentation, a hint between two expressions needs to justify that these two expressions are related
via the calculation operator. For example:

The last of the three calculations above is set in the context of integers, for which we use the type symbol “ℤ”.
The infix operators for addition and multiplication have been declared as follows:
Declaration: _+_ : ℤ → ℤ → ℤ
Declaration: _·_ : ℤ → ℤ → ℤ
For the basic laws for these, we follow the presentation in chapter 15 of LADM:
Axiom (15.1) (15.1a) “Associativity of +”: (a + b) + c = a + (b + c)
Axiom (15.1) (15.1b) “Associativity of ·”: (a · b) · c = a · (b · c)
Axiom (15.2) (15.2a) “Symmetry of +”: a + b = b + a
Axiom (15.2) (15.2b) “Symmetry of ·”: a · b = b · a
Axiom (15.3) “Additive identity” “Identity of +”: 0 + a = a
Axiom (15.4) “Multiplicative identity” “Identity of ·”: 1 · a = a
Axiom (15.5) “Distributivity” “Distributivity of · over +”: a · (b + c) = a · b + a · c
Axiom (15.9) “Zero of ·”: a · 0 = 0
In particular for theorems following LADM, we will be listing also theorem numners, such as (15.3). Theorem
numbers can also be used as theorem references; these include the round parentheses, and never contain spaces.
