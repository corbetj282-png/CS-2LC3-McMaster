Preloaded here are propositional and predicate logic (but no sets), and natural numbers. For the order ≤ and the strict-order < on ℕ, the
monotonicity, isotonicity and antitonicity properties are now more consistently named, e.g., “≤-Isotonicity of suc”.
For these, and for other useful theorems about the natural numbers see the list of preloaded theorems you can access via the “cell action
menu” that pops up when you click the cell number of a code cell.
Most proofs here, with two exceptions that are pointed out, can be quite short.

We have a new type constructor for bags, also called “multisets”:
Declaration: Bag : Type → Type
Bag comprehensions ⟅ x ❙ R • E ⟆ work analogously to set comprehensions; they are written using the “bag brackets” ⟅ ... ⟆ (type
\lbag and \rbag) provided by Unicode.

comprehensions where the body expression is just the single variable from the declaration part:
