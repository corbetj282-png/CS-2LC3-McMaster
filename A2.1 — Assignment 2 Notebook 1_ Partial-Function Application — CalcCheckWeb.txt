Partial-Function Application
[8]

A univalent relation is also called a partial function.
Note that our function types t₁ → t₂ are disjoint from our relation types t₁ ↔ t₂.
Therefore, if f : t₁ ↔ t₂ is a partial function (i.e., a univalent relation), and if a : t₁ is a potential argument, then we cannot write “f a” to
apply f to a, since that would require f to be of a function type.
To bridge this gap, we introduce the special application operator _@_ for partial functions, with the same precedence and associating behaviour
as function application:

We want to be able to prove interesting things only about well-defined partial-function applications “f @ x” where f actually is a partial
function, and x is in its domain:

Axiom “Partial-function application”:
univalent f ∧ x ∈ Dom f
⇒ (f @ x = y ≡ x ⦗ f ⦘ y)
