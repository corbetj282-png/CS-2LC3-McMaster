A binary relation is a set of pairs.
Thereforem, the type “t₁ ↔ t₂” of all binary relations from t₁ to t₂ is the type of all possible sets of pairs with first constituent of type t₁
and second constituent of type t₂:
“Definition of ↔”:

[4]

t₁ ↔ t₂

=

set ❰ t₁ , t₂ ❱

For infix relationship we use the following notation:
`a ⦗ R ⦘ b`


This means that a is related with b via relation R.
The brackets in this notation are called “tortoise shell brackets” by Unicode. Type \lrel or \(( for ⦗, and \rrel or \)) for ⦘.

Relationship turns a relation R : A ↔ B into a binary infix predicate _⦗ R ⦘_ (this “mixed underscore” notation is not yet supported by
CalcCheck).
The axiom “Infix relationship” is the connection between the infix relationship notation a ⦗ R ⦘ b and the set membership of pairs ⟨ a , b ⟩
∈ R, and will therefore be needed for justifying basic relationship properties via set theory.
