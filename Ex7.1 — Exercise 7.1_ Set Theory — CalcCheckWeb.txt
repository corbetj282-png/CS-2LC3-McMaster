Membership Properties
[3]

The set operations and properties from Homework 14 are also preloaded here.
Recall that the set of elements of type t that satisfy a common property P is denoted by the “set comprehension” written as follows:
{x : t ❙ P }
(Here, P is an expression in which x can occur as a free variable.)
More generally, the elements may be the values of expression E, which again may have free occurrences of x, written in set comprehensions of
the following shape:
{x : t ❙ P • E}
If we assume a predicate
p : t → 𝔹


and a function
f : t → t'
then we can consider the set S defined via the following set comprehension:
S

=

{x : t ❙ p x • f x}

Clearly, an item y : t' is an element of S if it is f x for some x satisfying p x.
