Inductive Theory of Sequences
[2]

Here we develop a theory of sequences essentially along the lines of LADM chapter 13. At the type level, we have the new type constructor Seq:
Declaration: Seq : Type → Type
For example, “Seq ℕ” is the type of finite sequences of natural numbers, and “Seq (Seq 𝔹)” is the type of finite sequences of finite
sequences of Boolean values, which can be used to model the type of finite sequences of words of bits.
Sequences are introduced as an inductive type with the following constructors named as in LADM:
Declaration: 𝜖 : Seq A
Declaration: _◃_ : A → Seq A → Seq A
“𝜖” (type \emptySeq or \eps) stands for the empty sequence.
For an element x : A and a sequence xs : Seq a, the sequence x ◃ xs has x as its first element, also called “head”, and xs as its “tail”.
For the symbol “◃”, type \cons.
The binary operator ◃ associates to the right.
Informally, we use Haskell notation for lists, e.g. “[5, 3, 6]”, where LADM uses (very occasionally) angle brackets: “⟨ 5, 3, 6 ⟩”.


This informal Haskell-like notation is not supported by CalcCheck!
We just use it to “informally visualise” the behaviour of sequence operations, for example:
[5, 3, 6]
=⟨ Informal list notation ⟩
5 ◃ [3, 6]
=⟨ Informal list notation ⟩
5 ◃ (3 ◃ [6])
=⟨ Informal list notation ⟩
5 ◃ (3 ◃ (6 ◃ []))
=⟨ Informal list notation ⟩
5 ◃ (3 ◃ (6 ◃ 𝜖))
=⟨ ◃ associates to the right ⟩
5 ◃ 3 ◃ 6 ◃ 𝜖

The induction principle for sequences implemented in 🙶By induction🙷 proofs is the following:
P[xs ≔ 𝜖]
(∀ xs : Seq A ❙ P • (∀ x : A • P[xs ≔ x ◃ xs]))
(∀ xs : Seq A • P)

⇒
⇒

Later, we will be using this directly.
For now, we use the built-in 🙶By induction on🙷 support for sequences: An induction proof for either just P, or for ∀ xs : Seq A • P (it
works the same for both goal statements), takes the following shape:
By induction on `xs : Seq A`:
Base case:
⟪ Proof for `P[xs ≔ 𝜖]` ⟫
Induction step:
⟪ Proof for `∀ x : A • P[xs ≔ x ◃ xs]` ⟫
⟪ using: Induction hypothesis `P` ⟫
Be careful to introduce a fresh variable instead of x for proving theorems that mention x!
(When the type of the sequence elements is specified, then use that type, for example:
By induction on `xs : Seq ℕ`:
However, where the type of the sequence element is not specified, use A to stand for that type, and ignore the resulting “free variables” warning.)

Snoc
[12]

While cons _◃_ adds an element to the beginning of a sequence, snoc _▹_ adds an element at the end, for example, [2, 5, 3] ▹ 7 = [2,
5, 3, 7].
The operator ▹ (type “\snoc”) associates to the left; it has the same precedence as ◃, and ◃ mutually associates to the right also with ▹, that
is:


x ◃ xs ▹ y
