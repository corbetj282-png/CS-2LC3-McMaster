Here we continue the redevelopment of the theory of the natural numbers from scratch started in H18: Instead of having the successor operator
suc, induction is based here on 0 and (_+ 1), using the following explicitly stated induction principle:
Axiom “Induction over ℕ”:
P[n ≔ 0]
⇒ (∀ n : ℕ ❙ P • P[n ≔ n + 1])
⇒ (∀ n : ℕ • P)
(All propositional logic and predicate logic are preloaded here, and four hint items are allowed per hint.)

[2]

Recall that “Induction over ℕ” can be used to prove properties of the shape (∀ n : ℕ • P) by supplying subproofs for the base case P[n
≔ 0] and the induction step (∀ n : ℕ ❙ P • P[n ≔ n + 1]), normally organised in the following pattern:
Theorem “P”: ∀ n • P
Proof:

Important: Using “Induction over ℕ” with two subproofs can only prove universally-quantified goals, that is, goals of shape (∀ n : ℕ
• P)!
